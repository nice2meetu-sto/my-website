# 2026 연차사용촉진 제출현황 대시보드

서울관광재단 인사팀의 **미사용 연차유급휴가 사용촉진**(근로기준법 제61조) 업무 지원 도구입니다.
직원이 제출한 「미사용 연차유급휴가 사용시기 지정통보서」를 담당자가 이 대시보드에서 확인·검증하고,
Google Sheets에 규정 표기 형식으로 기록합니다.

- **지정통보 제출 기한: 2026-07-20**
- 프론트: 단일 HTML 파일 + vanilla JS (프레임워크·빌드 없음, 로컬 `file://` 로 열어도 동작)
- 백엔드: Google Apps Script 웹앱 (GET 전용 JSON API)

## 구성 파일

| 파일 | 설명 |
|---|---|
| `연차촉진대시보드.html` | 대시보드 본체 (브라우저로 열기) |
| `Code.gs` | Apps Script — 읽기(`data`) + 쓰기(`submit`/`clear`) API |
| `README.md` | 이 문서 |

## 설치 · 연결 순서

### 1) Google Sheets 준비

1. 인사팀 연차 엑셀을 새 Google 스프레드시트에 업로드(또는 붙여넣기)합니다.
2. 데이터가 들어있는 **시트 탭 이름을 `연차현황`** 으로 맞춥니다.
3. 1행은 헤더, 2행부터 직원 데이터여야 합니다. 열 구성:

   | 열 | 헤더 | 예시 |
   |---|---|---|
   | A | 연번 | 1 |
   | B | 상태 | 재직 / 비대상(휴직) / 비대상(퇴직예정) / 비대상(사용완료) |
   | C | 사번 | FT0001 |
   | D | 성명 | 김지현 |
   | E | 직급 | 1급 |
   | F | 소속 | 인사팀(전문위원) |
   | G | 근무지 | 서울웰컴센터 *(선택 · 소속팀의 하위 구분)* |
   | H | 입사일 | 2008-03-01 |
   | I | 부여연차 | 23 |
   | J | 사용 합계 | 11.25 |
   | K | 잔여 | 11.75 |
   | L | 지정 | (대시보드가 기록) |
   | **M** | **결과** | **(← 이 헤더를 직접 추가하세요)** |

   > ⚠️ **`결과` 헤더를 반드시 추가**하세요. 대시보드가 검증 결과(일치/불일치)를 이 칼럼에 기록합니다.
   > 위 열 문자는 예시일 뿐이며, **헤더 이름만 맞으면 위치가 달라도 자동 인식**됩니다(공백 무시). 열을 삽입/이동해도 됩니다. `사용 합계`/`사용합계`, `근무지`/`센터` 모두 허용.
   > **근무지(G)** 는 선택 항목입니다. 값이 있으면 팀별 현황에서 소속팀 아래 **근무지(센터)별로 다시 묶어** 보여주고, 비어 있으면 팀원을 평면 목록으로 표시합니다.

- **상태 = `재직` 인 직원만 촉진 대상자**로 집계됩니다(그 외는 하단 비대상자 섹션에 참고 표시).
- 제출 여부는 별도 칼럼 없이 **`지정`(K) 값이 비어있지 않으면 제출완료**로 판정합니다.

### 2) Apps Script 배포

1. 스프레드시트 상단 메뉴 → **확장 프로그램 → Apps Script**.
2. 기본 `Code.gs` 내용을 지우고, 이 저장소의 **`Code.gs` 전체를 붙여넣기** 후 저장.
3. 우측 상단 **배포 → 새 배포**.
4. 유형 선택(톱니바퀴) → **웹 앱**.
5. 설정:
   - 설명: 자유
   - 실행 계정: **나(me)**
   - 액세스 권한: **모든 사용자(Anyone)**
6. **배포** → 권한 승인(최초 1회) → **웹 앱 URL 복사** (`.../exec` 로 끝나는 주소).

### 3) 대시보드에 URL 연결

1. `연차촉진대시보드.html` 을 편집기로 엽니다.
2. 상단의 상수에 복사한 URL을 붙여넣습니다:

   ```js
   const SCRIPT_URL = "https://script.google.com/macros/s/xxxxxxxx/exec";
   ```

3. 저장 후 파일을 브라우저로 엽니다(더블클릭 `file://` 또는 GitHub Pages 업로드 모두 가능).

## 사용법

### 탭 1 · 팀별 제출 현황
- 상단 KPI: **대상자 수 / 제출완료 / 미제출 / 제출률** + **마감 D-day**(임박 시 빨강).
- 팀 카드를 펼치면 팀원별 잔여연차·제출/결과 배지·지정 내역이 보입니다.
  근무지(센터) 값이 있는 팀은 **소속팀 아래 근무지별 소그룹**으로 나뉘어 표시됩니다.
- 모든 인원 목록(팀원·비대상자·검색 자동완성)은 **사번 순**으로 정렬됩니다.
- 필터: 전체 / 미제출만 / 제출완료만 / 불일치만. 「미제출 많은 팀 우선」 정렬 옵션.
- **미제출자 명단 복사**: 팀별 또는 전체를 `팀명: 이름, 이름` 형식 텍스트로 클립보드에 복사(독촉 공지용).
- 비대상자(휴직/퇴직예정/사용완료)는 하단에 접힌 상태로 참고 표시(카운트 미포함).

### 탭 2 · 검색 · 지정 입력
1. 성명 또는 사번으로 검색(부분일치, 자동완성). **동명이인은 사번·소속으로 구분** 표시됩니다.
2. 직원 선택 → 발생/사용/미사용(잔여) 연차 확인.
3. **행 추가형 입력**: [시작일] ~ [종료일(선택)] + [일수]. 종료일을 비우면 단일 날짜.
   - `2026-07-05` + `3` → 저장 표기 `7/5(3일)`
   - `2026-08-12 ~ 2026-08-14` + `2.5` → `8/12~14(2.5일)`
   - 월을 넘는 범위 → `8/30~9/2(3일)`
4. 실시간으로 **잔여 − 합계 = 차이** 를 표시하고 **일치/불일치 배지**를 보여줍니다.
   부동소수점 오차 없이(일수 ×1000 정수 계산) 0.125 단위까지 정확히 판정.
5. **저장**: 일치 여부와 무관하게 항상 가능. 불일치면 확인창을 한 번 표시. 저장 시
   `지정`(K)에 표기 문자열, `결과`(L)에 `일치`/`불일치` 가 함께 기록됩니다.
6. 이미 제출된 인원은 기존 지정 내역이 **자동 역파싱되어 수정 모드**로 열리며,
   **제출 취소** 버튼으로 미제출 상태로 되돌릴 수 있습니다.

## 재배포 시 주의

코드(`Code.gs`)를 수정한 뒤에는 **배포 → 배포 관리**에서 기존 배포를 편집하거나,
**새 배포**로 다시 배포해야 변경 사항이 반영됩니다.

- **같은 URL 유지**: 「배포 관리 → 편집(연필) → 버전: 새 버전 → 배포」
- **새 URL 발급**: 「새 배포」를 하면 URL이 새로 생성되므로, 이 경우 `SCRIPT_URL` 값을 갱신해야 합니다.

## API 요약 (참고)

모든 응답은 `{ ok: true/false, ... }` JSON. `callback` 파라미터가 있으면 JSONP로 감싸 반환(브라우저 CORS 회피).

| 요청 | 동작 |
|---|---|
| `?action=data` | 전체 행 반환 (`updatedAt`, `rows[]`) |
| `?action=submit&empId=..&designated=<encoded>&result=일치` | 해당 사번의 K·L열 덮어쓰기(수정 재제출) |
| `?action=clear&empId=..` | 해당 사번의 지정·결과를 비움(제출 취소) |

- 쓰기는 `LockService` 로 동시 쓰기를 보호합니다.
- `POST` / `google.script.run` / `HtmlService` 는 사용하지 않습니다(재단 시스템 패턴).
